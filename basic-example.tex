\section{Introduction}
This is a basic example of a \LaTeX\ document. \LaTeX\ is widely used for scientific and technical documents because it handles formatting and mathematical notation exceptionally well.

You can easily make text \textbf{bold}, \textit{italicized}, or \underline{underlined}.

\section{Mathematics}
One of the strongest features of \LaTeX\ is its ability to render complex equations. You can write math inline, like $E = mc^2$, or as a displayed equation:

\begin{equation}
    x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
\end{equation}
